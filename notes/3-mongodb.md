? 3.1 This is a short walkthrough of setting up a MongoDB database from scratch at www.mongodb.com. First, log in or sign up on the website. Then, go to the Organization tab (or create one if you don't have one yet). You will see a list of projects. Click the "New Project" button. Next, we can add tags to categorize our project, name it, add additional users to access our DB if it needs. Then we have to create a cluster of the database by clicking "Create" button. Then, we'll name our Database and choose rate. Then, after short time a new DB should be created. Now, to get the "connection string" that we need for our app click on "Get connection string" button at the database overview page. Next, we'll click on "Add data" to add a new collection for users. We'll click then "Create database" and create a new collections called "users".
